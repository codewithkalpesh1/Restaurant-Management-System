COZY CORNER - RESTAURANT MANAGEMENT SYSTEM
Technology: HTML5, CSS3, Bootstrap 5 and JavaScript only.
No PHP, server, or database is required.

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome / Edge.
3. Click ADMIN in the top navigation to open the admin login.

DEMO ADMIN LOGIN
Email: admin@cozycorner.com
Password: admin123

ADMIN FEATURES
Dashboard, Manage Food (add/edit/delete), Manage Categories, Manage Reservations (confirm/delete), Manage Gallery (add/delete), Contact Messages, Logout and Back to Website.

DATA STORAGE
Reservations, contact messages, menu changes and gallery/category changes are stored in browser localStorage. Admin login uses sessionStorage for this demo. Data is local to the browser/device and is not shared with other users. Clearing browser data removes saved records.

IMAGE PATH
Use existing image paths such as img/about1.jpg. To add a new image, copy it into the img folder and enter its relative path in the admin form.

NOTE
This is a frontend academic project/demo. Real multi-user authentication, secure admin access and central database storage require a backend in a future version.
